  • Fills out PreciseFP intake form (one time)
  • Clicks secure upload link for documents
  • Links accounts in RightCapital
  • Books meetings via Calendly link

Phase 1 Client Intake

The client receives a PreciseFP link from their advisor and fills out the intake form. If incomplete, automated reminders follow up.

StepActorAction
1.1AdvisorSends personalized PreciseFP intake link to prospect via email or text
1.2ClientOpens the link and fills out the form: demographics, financials, beneficiaries, spouse info, product interests

Phase 2 Automated Processing

Our server receives the webhook, fetches data from PreciseFP, extracts 30+ fields, scrubs SSN, and determines products.
flowchart TD A["Webhook received"] --> B{"Already\nprocessed?"} B -- Yes --> C["Skip (idempotency)"] B -- No --> D["Fetch engagement data\nfrom PreciseFP API"] D --> E["Extract 30+ fields:\ndemographics, financials,\nspouse, beneficiaries"] E --> F["🔒 SSN scrubbed\nimmediately"] F --> G["Determine products\nfrom template ID"] G --> H{"Existing\nclient?"} H -- New --> I["Create Wealthbox contact\n+ tags + custom fields\n+ pipeline + spouse"] H -- Existing --> J["Update contact\nProcess net-new\nproducts only"] style A fill:#7c3aed,stroke:#6d28d9,color:#fff style D fill:#7c3aed,stroke:#6d28d9,color:#fff style E fill:#7c3aed,stroke:#6d28d9,color:#fff style F fill:#dc2626,stroke:#b91c1c,color:#fff style G fill:#7c3aed,stroke:#6d28d9,color:#fff style I fill:#059669,stroke:#047857,color:#fff style J fill:#059669,stroke:#047857,color:#fff
🔒 Security: SSN is extracted for processing but immediately scrubbed from memory. It is never stored in our database, never sent to Wealthbox, ShareFile, or any downstream platform. All data encrypted with AES-256-GCM. Full audit trail for FINRA/SEC compliance.

New Client vs. Returning Client

ScenarioWhat Happens
New ClientFull Wealthbox contact created with tags (Prospect + product tags), custom fields (Anniversary Date, Product Path, Referral Source), pipeline opportunities, spouse linked as household member, licensing verified
Returning ClientExisting contact found by email — base data NOT re-entered. Only net-new products processed. Tags merged, custom fields updated. No duplicate contacts created.

Every action is logged to PostgreSQL for FINRA/SEC compliance. Full audit trail maintained.

🔒 Security Summary:
• AES-256-GCM encryption for all data at rest
• TLS 1.2+ for all data in transit
• SSN never stored — scrubbed immediately after extraction
• PII masked in all logs (emails, phone numbers, SSN)
• Webhook authentication (HMAC-SHA256 for Wealthbox, shared secret for PreciseFP)
• Admin API key required for all management endpoints
• Full audit trail for SEC examination readiness
